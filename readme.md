## ✨ Sobre o Projeto

Este repositório apresenta um projeto desenvolvido com foco em **acessibilidade digital**, aplicando boas práticas para garantir que diferentes públicos consigam utilizar o sistema de forma inclusiva, intuitiva e eficiente.

---

## 🎯 Objetivo

Este projeto tem como finalidade:

* Aplicar conceitos de acessibilidade na prática
* Promover inclusão digital
* Melhorar a experiência do usuário
* Atender aos requisitos da disciplina

---

## ♿ Recursos de Acessibilidade

O projeto contempla:

* 🎨 Contraste adequado de cores
* ⌨️ Navegação completa por teclado
* 🗣️ Compatibilidade com leitores de tela
* 🧩 Estrutura HTML semântica
* 🖼️ Textos alternativos em imagens
* 🔔 Feedbacks visuais e interativos claros

---

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript

---

## 📱 Responsividade

O projeto foi desenvolvido pensando em diferentes dispositivos:

* 💻 Desktop
* 📱 Mobile
* 📲 Tablets

Layout adaptável para melhor experiência em qualquer tela.

---

## 👨‍🏫 Sobre a Disciplina

Este trabalho foi desenvolvido como parte da disciplina de **Acessibilidade**, ministrada pelo professor **Sandro Sá**, com foco na construção de soluções digitais mais inclusivas.

---

A acessibilidade é essencial para garantir que a tecnologia seja para todos.
